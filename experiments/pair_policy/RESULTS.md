# Pair Policy：历史实验记录

以下结果用于保留实验上下文，不代表跨硬件或跨版本的通用结论。

## 棋力快照

gen25 的 3,000 个验证局面：

| 指标 | 结果 |
| --- | ---: |
| 第一子 CE / top-1 | 2.197 / 62.97% |
| 第二子 CE / top-1 | 2.173 / 60.27% |
| 第二子 top-20 recall | 99.47% |
| 主价值 / 条件价值 MAE | 0.585 / 0.572 |

在黑 400、白 1200 的搜索预算下，第一版候选对当时 incumbent 的两批换色评估合计
为 34:26。后续训练降低了离线损失，但门禁结果没有同步改善，因此未替换候选。

## 吞吐快照

记录时间：2026-07-11。硬件为两张 A800，每卡一个 worker、32 个 CPU 线程，
黑 400、白 1200，共生成 192 局。

| 路径 | 每卡并发棋局 | 对局/秒 | 搜索叶子/秒 |
| --- | ---: | ---: | ---: |
| 完整网络基线 | 12 | 5.203 | 124,407 |
| Pair policy | 12 | 6.115 | 132,803 |
| Pair policy | 24 | 7.619 | 156,268 |

最终配置相对基线的对局吞吐提高约 46.4%，按搜索叶子归一化提高约 25.6%。该结果
依赖当时的模型、TensorRT 版本、CPU 拓扑和搜索实现；新环境应重新执行固定预算基准。

32 与 64 CPU 线程的 40 局换色对照为 19:21，未观察到显著棋力差异。
